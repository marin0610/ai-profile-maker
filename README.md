# AIに覚えてもらう プロフィール作成

フォームに自分の情報を入力すると、ChatGPTやClaudeなどのAIチャットにそのまま貼り付けて「私のことを覚えて」と渡せる、整ったプロフィール文（テキスト）が自動で作られるアプリです。

## 使い方

1. 基本情報・好きなもの・苦手なもの・目標・話し方の好みなどを入力します（書きたくない項目は空欄でOK。空欄は文章に出ません）
2. 画面下の「できあがり」に文章が自動生成されます
3. 「文章をコピーする」を押して、AIチャットの最初のメッセージに貼り付けます

## 特徴

- 生年月日・血液型・MBTIも選択式で入れられます
- 性格・特徴はチップをタップして選択（明るい、好奇心旺盛、直感で動く、など13種＋自由記入）
- 話し方の好みはチップをタップするだけ（タメ口／敬語、短め／詳しく、選択肢を出す、忖度なし、など複数選択可）
- 「やってほしくないこと・NG」もチップで選択（勝手に決めないで、説教っぽいのはNG、上から目線はNG、など8種）
- 配慮してほしいこと（触れてほしくない話題・苦手な場面など）も書けます
- おまけの「簡易MBTI診断」付き：12問の2択に答えると目安のタイプが出て、そのままプロフィールに反映できます
- 入力内容はブラウザ（localStorage）に自動保存されるので、閉じても続きから再編集できます。サーバーには送信されません
- テキストファイルとして保存するボタン、記入例を入れるボタン、全部消すボタン付き
- スマートフォンでも使いやすい1カラムデザイン
